# Frozen manuscript for arXiv replacement v3

This folder preserves the manuscript frozen on 2026-10-01 for replacement of
[arXiv:2409.14492](https://arxiv.org/abs/2409.14492). The files are named for the
intended v3 submission; that name does not by itself certify publication.

- `arxiv-2409.14492-v3.tex`: complete, standalone LaTeX source.
- `arxiv-2409.14492-v3.pdf`: locally compiled, 24-page PDF.
- `arxiv-2409.14492-v3-source.zip`: source archive containing the same `.tex` file.
- `SHA256SUMS.txt`: hashes of these three frozen files.

The three figures are generated by inline TikZ code. There are no external
image files or external bibliography files. The source archive contains no
Lean files; the Lean project and recorded verification are at the repository root.

The manuscript retains the author's existing arXiv licence,
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
The repository's Apache 2.0 licence applies to the Lean project and verification
code, and does not change the manuscript's licence.
